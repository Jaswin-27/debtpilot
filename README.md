# DebtPilot

## GitHub Repository

[View Source Code](https://github.com/Jaswin-27/debtpilot.git)
**A safety-first debt planning system for people managing multiple active debts.**

DebtPilot helps a user understand how much money is safely available for debt repayment, which debts should be prioritized, and when a normal repayment plan is no longer financially feasible.

The core design principle is simple:

> **The model has language authority, not financial authority.**

All financial decisions are made by a deterministic Python engine. The AI layer is optional and is used only to explain an already-verified plan in clear language.

---

## Why DebtPilot?

Someone may have several obligations at the same time:

- credit-card balance
- personal loan
- BNPL payment
- money owed to friends or family

But all of those debts compete for the same monthly income.

A normal chatbot can produce advice, but financial planning needs predictable rules, explainable calculations, and hard safety boundaries.

DebtPilot separates those responsibilities:

```text
User financial data
        ↓
Input validation
        ↓
Protect essential expenses
        ↓
Calculate safe debt budget
        ↓
Calculate minimum obligations
        ↓
Feasibility check
        ↓
 ┌───────────────────────┐
 │ Month is feasible     │
 │                       │
 │ Rank debts            │
 │ Allocate payments     │
 │ Validate the plan     │
 └──────────┬────────────┘
            │
            ▼
        Plan Proof

OR

 ┌───────────────────────┐
 │ Month is infeasible   │
 │                       │
 │ Stop optimization     │
 │ Trigger distress mode │
 │ Show verified support │
 └──────────┬────────────┘
            │
            ▼
 Optional explanation layer
```

## Key Features

### Protected essential expenses
Rent, food, transport, and other essential living costs are protected before any debt allocation is calculated.

### Deterministic debt planning
Ranking and payment amounts are calculated by Python rules rather than generated by an LLM.

### Unknown APR stays unknown
If an interest rate is missing, DebtPilot does not guess it and does not silently treat it as `0%`.

### Minimum-payment feasibility check
DebtPilot first checks whether all supplied minimum obligations fit inside the safe debt budget.

### Safe surplus allocation
When the month is feasible, minimums are handled first and the remaining safe surplus is directed according to the deterministic ranking rules.

### Income-shock rebuild
The user can reduce monthly income and rebuild the plan immediately.

### Financial Distress Mode
If the safe debt budget cannot cover minimum obligations, normal repayment optimization stops.

### Plan Proof
Every generated plan is validated against hard safety checks before it is shown.

### Optional Gemini explanation
Gemini may explain the verified result, but it cannot change financial values, ranking, safety status, or payment amounts.

### Deterministic fallback
If Gemini or the internet is unavailable, DebtPilot still produces a readable explanation without breaking the application.

---

## Safety Model

DebtPilot intentionally prevents unsafe behavior.

A verified plan checks that:

- essential expenses remain protected;
- suggested payments never exceed the safe debt budget;
- no payment is negative;
- no payment exceeds the supplied debt balance;
- no missing APR is invented;
- no new borrowing is suggested to service old debt;
- the application never collects or transfers money.

DebtPilot is advisory only.

## Example

### Normal month

```text
Monthly income         ₹28,000
Protected essentials   ₹13,000
Safe debt budget       ₹15,000
Minimum dues            ₹9,500
Safe surplus            ₹5,500
```

Example debts:

| Debt | Balance | Minimum Due | APR |
|---|---:|---:|---:|
| Credit Card | ₹32,000 | ₹2,800 | 39% |
| Personal Loan | ₹45,000 | ₹4,200 | 16% |
| BNPL | ₹8,000 | ₹1,500 | 0% |
| Friend / Informal | ₹5,000 | ₹1,000 | Unknown |

The system first protects the ₹13,000 of essential expenses, then handles minimum obligations, and finally allocates the safe surplus.

### Income shock

If monthly income drops from ₹28,000 to ₹16,000:

```text
New income             ₹16,000
Protected essentials   ₹13,000
Safe debt budget        ₹3,000
Minimum dues            ₹9,500
Shortfall               ₹6,500
```

DebtPilot switches to **Financial Distress Mode** and pauses normal payment optimization instead of suggesting an unsafe workaround.

---

## Ranking Logic

DebtPilot uses transparent deterministic rules:

1. Protect essential expenses first.
2. Treat overdue debt as urgent.
3. Prefer higher **verified** APR among normal debts.
4. Never use an unknown APR for APR-based ranking.
5. Use earlier due date as a tie-breaker.
6. Handle minimum obligations before extra repayment.
7. Direct safe surplus toward the highest-ranked eligible debt.

---

## Plan Proof

Before displaying a normal payment plan, DebtPilot verifies:

```text
✓ Protected essentials untouched
✓ Payments within safe budget
✓ No negative payments
✓ No payment exceeds debt balance
✓ No APR invented
✓ No new borrowing
✓ No payment collection
```

---

## Distress Mode

DebtPilot activates Financial Distress Mode when:

- monthly income falls below protected essential expenses, or
- the safe debt budget is lower than total minimum obligations.

In distress mode:

- normal payment optimization is paused;
- essential expenses remain protected;
- the app does not invent a repayment trick;
- verified financial / consumer support resources are shown;
- wellbeing support is presented separately when relevant.

---

## AI Architecture

The AI layer is intentionally restricted.

```text
Python engine
    ↓
Verified structured plan
    ↓
Safety validation
    ↓
Gemini (optional)
    ↓
Natural-language explanation
```

Gemini cannot change:

- payment amounts
- debt ranking
- APR
- due dates
- shortfall
- distress status
- Plan Proof results

If Gemini is unavailable, DebtPilot uses a deterministic fallback explanation.

## Run Locally

### 1. Create a virtual environment

```powershell
py -m venv .venv
```

### 2. Activate it

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Verify the engine

```powershell
python verify.py
```

Expected output:

```text
DebtPilot final verification: PASS (10/10 scenarios)
```

### 5. Start the application

```powershell
python -m streamlit run app.py
```

## Optional Gemini Setup

DebtPilot works without Gemini.

To enable the AI explanation layer, create a local `.env` file:

```text
GEMINI_API_KEY=your_real_api_key
GEMINI_MODEL=
```

`GEMINI_MODEL` may be left blank so the application can discover a compatible model.

> Never commit your real `.env` file or API key to GitHub.

## Verification

`verify.py` covers important cases including:

- normal month;
- unknown APR;
- genuine `0%` APR;
- reduced income;
- income below essential expenses;
- no debts;
- overpayment prevention;
- invalid negative values;
- unknown due date;
- exact-budget case.

Run:

```powershell
python verify.py
```

before every major submission or deployment.

## Scope

DebtPilot does **not** currently include:

- payment collection;
- UPI / card payments;
- bank-account integration;
- OCR statement parsing;
- authentication;
- credit-score prediction.

These are intentionally outside the current scope so the system remains focused on safe planning and explainability.
